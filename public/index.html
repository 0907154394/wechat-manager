Cloudflare Worker

🌐Cloudflare Worker là dịch vụ trung gian miễn phí — khi có OTP mới, app tự đẩy lên Worker.
🔗Khách hàng vào link /c/token để lấy OTP — link này ổn định, không đổi dù tắt/mở lại app.
📋Deploy file worker/index.js lên Cloudflare (miễn phí), bind KV namespace tên OTP_KV, thêm secret PUSH_SECRET.

Google Client Credentials (Gmail API)

🔑Cần thiết lập Credentials từ Google Cloud Console để sử dụng Gmail API.
🔗Đăng ký Redirect URI trên Google Console: http://localhost:3000/api/auth/google/callback
